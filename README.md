# FLI Holdings — RGA Copilot

Financial analysis dashboard for Grupo Nama. Upload monthly Excel data and optional qualitative documents; the system runs a quant + qual + synthesis pipeline and surfaces KPIs, scenarios, and strategic signals.

---

## Requirements

| Tool | Version |
|------|---------|
| Python | 3.11+ |
| Node.js | 18+ |
| npm | 9+ |

> macOS only: install [Tesseract](https://brew.sh) for OCR on image docs: `brew install tesseract`

---

## First-time setup

### 1. Clone

```bash
git clone https://github.com/Emilio-Mtz-bit/FLI-Holding-Agents.git
cd FLI-Holding-Agents
```

### 2. Python virtual environment

```bash
cd rga-copilot
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cd ..
```

### 3. Dashboard dependencies

```bash
cd dashboard
npm install
cd ..
```

### 4. API key

Create `api/.env`:

```
ANTHROPIC_API_KEY=sk-ant-...
```

---

## Running the app

Start both servers with one command from the repo root:

```bash
make dev
```

- **API** → `http://localhost:8000`
- **Dashboard** → `http://localhost:5173`

To run them separately:

```bash
make api        # FastAPI backend only
make dashboard  # Vite dev server only
```

## Using the dashboard

### Setup page

1. Upload the monthly **Excel file** (`.xlsx`) — required.
2. Optionally upload **qualitative documents** (PDF, PNG, JPG, Markdown) for strategic signal extraction.
3. Set the period name, year, company, and break-even target EBITDA.
4. Click **Run Analysis** and wait for the pipeline to complete (~30–60 s depending on document volume).

### Overview page

Displays after analysis completes:

- **Hero metrics** — total revenue, EBITDA, gross margin, payroll ratio
- **Por Sucursal** — per-branch revenue, EBITDA, gross margin table
- **Category Mix** — donut chart of revenue by category
- **Executive Summary** — LLM-generated quant narrative
- **Señales Estratégicas** — sentiment gauge, company positioning, strengths, risks, and growth factors extracted from qualitative documents (only shown if qual docs were uploaded)

### What-If Lab

- Toggle and tune the 5 default scenarios (cost increase, branch closure, mix shift, payroll reduction, salary increase)
- Add custom scenarios via the **Add Scenario** drawer
- Waterfall chart updates in real time
- Break-even ticket calculator per branch

### Memo page

- View the full HTML memo generated by the synthesis agent
- Download as `.html`

## Troubleshooting

**`No module named 'fitz'`** — PyMuPDF not installed:
```bash
rga-copilot/.venv/bin/pip install pymupdf
```

**Port 8000 already in use:**
```bash
lsof -ti :8000 | xargs kill -9
```

**API key missing** — make sure `api/.env` contains `ANTHROPIC_API_KEY`.
